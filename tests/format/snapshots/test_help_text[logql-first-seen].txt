usage: logql.py first-seen [-h] [--since SINCE] [--end END] [--max-lines MAX_LINES] [--json] selector template

logql.py first-seen '<selector>' '<패턴>' [--since 1h] [--end <시각>]

템플릿(패턴 — templates 의 출력 그대로, `<_>` 가 자리표시)에 걸리는 창 안의 첫 줄 — `|>` 패턴 필터를 forward · limit 1 로 한 번.
`첫 발생 <시각>  <템플릿>` 과 그 줄, 창 안에 없으면 `창 안에 없음`.

계산은 백엔드(Loki)가 한다 — count_over_time · Patterns API 의 환원 결과만 받고, 원본 로그 줄은 예시 · 첫 발생 · 문맥에만 온다.
창(around 는 --ts ± --span)은 호출 디렉터리의 summary.txt 머리에 남는다. stdout 은 요약이고 --max-lines 에서 잘린다. --json 은 경로만.

positional arguments:
  selector              LogQL 스트림 selector — 예: '{namespace="x"}'
  template              패턴 — templates 출력의 템플릿 그대로

options:
  -h, --help            show this help message and exit
  --since SINCE         창 길이. 기본 1h
  --end END             창 끝 (now · -10m · unix초 · RFC3339). 기본 now
  --max-lines MAX_LINES
                        stdout 줄 수 상한. 기본 40 — 나머지는 호출 디렉터리의 summary.txt 에
  --json                stdout 에 요약을 찍지 않고 호출 디렉터리 경로만(파일은 항상 남는다)
