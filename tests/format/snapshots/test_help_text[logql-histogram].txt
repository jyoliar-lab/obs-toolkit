usage: logql.py histogram [-h] [--since SINCE] [--end END] [--max-lines MAX_LINES] [--json] [--by BY] [--step STEP]
                          selector

logql.py histogram '<selector>' [--by detected_level] [--since 1h] [--end <시각>] [--step 60s]

by 값별 · 구간별 건수 표 — `sum by (<by>) (count_over_time(<selector>[<step>]))` 를 구간 조회 한 번으로.
첫 줄은 창 · step · 구간 수 헤더, 그 뒤 행마다 `합  {레이블}  구간별 건수(오래된 것부터)`. 행은 합 내림차순이고 상한을 넘으면 꼬리에 뺀 행 수.
로그가 없으면 "데이터 없음"(0 과 다르다 — 건수 0 인 행은 0 으로 실린다).

계산은 백엔드(Loki)가 한다 — count_over_time · Patterns API 의 환원 결과만 받고, 원본 로그 줄은 예시 · 첫 발생 · 문맥에만 온다.
실제로 보낸 질의와 창은 호출 디렉터리의 summary.txt 머리에 남는다. stdout 은 요약이고 --max-lines 에서 잘린다. --json 은 경로만.

positional arguments:
  selector              LogQL 스트림 selector — 예: '{namespace="x"}'

options:
  -h, --help            show this help message and exit
  --since SINCE         창 길이. 기본 1h
  --end END             창 끝 (now · -10m · unix초 · RFC3339). 기본 now
  --max-lines MAX_LINES
                        stdout 줄 수 상한. 기본 40 — 나머지는 호출 디렉터리의 summary.txt 에
  --json                stdout 에 요약을 찍지 않고 호출 디렉터리 경로만(파일은 항상 남는다)
  --by BY               행의 레이블 축. 쉼표로 여러 개. 기본 detected_level
  --step STEP           구간 폭. 기본 창 길이/60 (최소 15s)
